Kebijakan Privasi

Aplikasi ini menggunakan OAuth untuk mengakses Google Drive Anda.

- Kami hanya membaca metadata file (nama file, link, ukuran, dll).
- Kami tidak menyimpan data pengguna secara permanen.
- Tidak ada informasi pribadi yang dibagikan ke pihak ketiga.
- Akses digunakan hanya untuk menampilkan daftar file secara lokal di aplikasi.
